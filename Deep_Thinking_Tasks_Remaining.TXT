━━━━━━━━━━━━━━━━━━━━━━━━━━

TESTS             — عدد وأسماء الاختبارات الجديدة + النتيجة الإجمالية
PARITY            — نتيجة 11/11
QUALITY GATE      — مخرجات hadith_sijil.py و Exit Code
GIT               — SHA الـ Commit + حالة الملفات المولّدة
REMAINING RISK    — المخاطر المتبقية / الديون الفنية المؤجلة
NEXT RESUME POINT — نقطة الاستئناف الدقيقة لأي جلسة قادمة
