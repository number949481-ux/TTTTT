## 🎯 1. نظرة عامة على النظام (System Overview)
النظام يمثل منصة متكاملة للربط الذكي بين واجهة Telegram Bot ومحرك أتمتة Genspark WebApp. يتيح إدارة ومزامنة مشاريع الويب المتعددة، المعاينة الحية الفورية (Instant Live Preview) في الثانية الأولى من التوليد، الفحص التلقائي لمستودعات وفروع GitHub مع إمكانية الاختيار المباشر بنقرة واحدة (1-Click Branch Selection)، وتوجيه واستدعاء أحدث نماذج الذكاء الاصطناعي بدقة تامة.

## 📐 2. مبدأ المعمارية الصارم (Single-File Doctrine)
* **المحرك الأساسي:** ملف بايثون مستقل وشامل (`01.03Genspark_claude-opus-5-code.py`) يحتوي على كافة عقود الموديلات وقواميس التحويل وآليات الاتصال بدون أي اعتماديات خارجية مبعثرة.
* **البوت التفاعلي:** ملف بايثون متكامل (`01.29_telegram_gen_bridge.py`) يدير حالة المستخدم، واجهات الأزرار، والربط البرمجي.
* **محرك كوين المستقل (P15):** موديول `qwen_engine.py` يحتوي منظومة Qwen.ai Direct كاملة (سلسلة الموديلات، سباق الحسابات + الضيف، التجديد التلقائي، حفظ كوكيز الفائز، استخراج الملخص) — و`04_upload_to_Fable_github.py` يستورده مع حقن اللوجر عبر `qwen_engine.configure(log_func=...)`.
* **العزل المحلي:** كافة الوثائق والتقارير محصورة ومحفوظة بالكامل داخل مجلد `W___webapp/docs/` لتسهيل النقل والتشغيل الفوري كـ Self-Contained Unit.

```text
│   ├── 📄 PROGRESS.md               ← المصدر الوحيد والأساسي للحقيقة الحية (SSOT)
│   ├── 📄 SESSION_LOG.md            ← سجل الجلسات والقرارات المعمارية

│   └── 📄 01.25_TASK_LOG.md         ← سجل مهام الإصدار الحالي النشط
└── 🧪 📁 tests/                     ← الجناح الثاني: كتالوج وسجلات وأدلة الاختبارات
    ├── 📄 README.md                 ← دليل بيئة الاختبارات وطرق التشغيل

```

## 🔗 4. إدارة سجل التقدم والمصدر الوحيد للحقيقة (SSOT Policy)
* **المصدر الوحيد للحقيقة (Single Source of Truth):** هو الملف الرئيسي: [PROGRESS.md](PROGRESS.md).
* **ممنوع التكرار:** لا توجد نسخ مكررة من `PROGRESS.md` لتفادي التضارب، ويتم الرجوع دائماً للمصدر الرئيسي في `docs/engineering/PROGRESS.md`.

## 🔄 5. بروتوكول «حدث سجل» الآلي المعتمد
1. **فحص التعديلات:** مراجعة التغييرات في الشفرات (`git diff`).
2. **بوابة الاختبارات الصارمة (Test Gate):** تشغيل `python -m unittest discover tests -v` والتأكد التام من خروج **Exit Code 0** (32/32 فحصاً).
3. **تحديث الـ SSOT:** تحديث ملف [PROGRESS.md](PROGRESS.md).

4. **مزامنة الوثائق:** تحديث سجلات المهام ومصفوفة التتبع وتقارير التراجع.
5. **مزامنة دفاتر الذاكرة:** تحديث `Root/ai_state.json` و `Root/memory.md`.
6. **الـ Commit المحمي:** حفظ الكود والتوثيق برقم الـ Commit المعتمد.
