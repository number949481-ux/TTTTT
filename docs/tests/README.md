## 🛡️ 4. قواعد ومبادئ الاختبارات الصارمة (Test-Before-Talk)
1. **ممنوع التوثيق الأعمى:** لا يتم تحديث أي سجل أو إغلاق أي مهمة إلا بعد التأكد من خروج الفحص بـ **`Exit Code 0`**.
2. **عزل زمن الشبكة:** الاختبارات مصممة كوحدات برمجية نقية تعمل في زمن قياسي (~0.015s) دون الاعتماد على شبكات خارجية غير مستقرة.
3. **حماية التراجع (Zero-Regression):** كل ميزة جديدة يجب أن تتضمن اختبارات تؤكد عدم كسر الميزات القديمة.
