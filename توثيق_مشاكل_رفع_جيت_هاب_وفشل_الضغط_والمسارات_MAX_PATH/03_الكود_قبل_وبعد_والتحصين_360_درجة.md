## 1️⃣ دالة التحصين المركزية: `_to_win_long_path`

تمت إضافة هذه الدالة في صدارة الملف لتكون المرجع الحاكم والموحد لتحويل أي مسار على نظام ويندوز إلى مسار موسع (Extended-Length Path) ببادئة `\\?\`:

```python
# 01.33_telegram_gen_bridge.py (L118-L135)
def _to_win_long_path(p: pathlib.Path | str) -> pathlib.Path:
    r"""تحويل المسار إلى صيغة المسار الطويل لويندوز (\\?\) لتجاوز سقف MAX_PATH (260 حرف).
    آمنة وغير مكررة (Idempotent): لو المسار محول بالفعل أو النظام مش ويندوز ترجعه كما هو."""
    if sys.platform != "win32":
        return pathlib.Path(p)
    resolved = str(pathlib.Path(p).resolve())
    if not resolved.startswith("\\\\?\\"):
        resolved = resolved.replace("/", "\\")
        if not resolved.startswith("\\\\?\\"):
            if resolved.startswith("\\\\"):
                resolved = "\\\\?\\UNC\\" + resolved.lstrip("\\")
            else:
                resolved = "\\\\?\\" + resolved
    return pathlib.Path(resolved)
```
